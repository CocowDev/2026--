## 三、环境变量配置（PowerShell）

> ✅ **推荐方式（Maven Wrapper）**：只需设置 `JAVA_HOME`，后端用 `.\mvnw.cmd` 代替 `mvn`，无需全局安装 Maven。
> ⚠️ 系统默认未设置 `JAVA_HOME`。**每次新开终端运行后端前，需先执行以下配置**（或加入 PowerShell `$PROFILE` 永久生效）。

```powershell
# 临时设置（当前会话生效）— 仅需 JAVA_HOME
$env:JAVA_HOME = "C:\Program Files\Java\jdk-17.0.17.10-hotspot"
$env:PATH      = "$env:JAVA_HOME\bin;$env:PATH"

# 验证
java -version
```

> 如需直接使用全局 `mvn` 命令（不用 mvnw.cmd），还需额外设置 MAVEN_HOME：
> ```powershell
> $env:MAVEN_HOME = "C:\Users\leero\.m2\wrapper\dists\apache-maven-3.9.6-bin\3311e1d4\apache-maven-3.9.6"
> $env:PATH = "$env:JAVA_HOME\bin;$env:MAVEN_HOME\bin;$env:PATH"
> mvn -v
> ```

### 永久生效（推荐，写入用户环境变量）
```powershell
[Environment]::SetEnvironmentVariable("JAVA_HOME", "C:\Program Files\Java\jdk-17.0.17.10-hotspot", "User")
# Maven Wrapper 已集成到项目，无需设置 MAVEN_HOME
```

> 配置一次即可，后续终端 `java` / `.\mvnw.cmd` 直接可用，无需重复设置。

## 四、数据库配置

### 连接信息（见 [backend/src/main/resources/application.yml](backend/src/main/resources/application.yml)）
| 项 | 值 |
|----|----|
| URL | `jdbc:mysql://localhost:3306/hotel_booking?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai` |
| 用户名 | `root` |
| 密码 | `123456` |
| 端口 | `3306` |
| 数据库名 | `hotel_booking` |

### 初始化（任选其一）

**方式 A：SQL 脚本初始化**（推荐先执行）
```powershell
mysql -u root -p123456 < database/init.sql    # 清空旧表
mysql -u root -p123456 < database/schema.sql   # 建库建表
mysql -u root -p123456 < database/seed.sql     # 种子数据
```
> ⚠️ `seed.sql` 中 admin 哈希明文为 `admin`；如执行了 seed.sql，则 [DataInitConfig](backend/src/main/java/com/hotel/booking/config/DataInitConfig.java) 因表非空**不会**再插入数据。

**方式 B：代码自动初始化**
- 不执行任何 SQL，仅建空库 `hotel_booking`
- 启动后端时 [DataInitConfig.java](backend/src/main/java/com/hotel/booking/config/DataInitConfig.java) 检测表为空自动插入种子数据
- 自动创建管理员账号：**admin / admin123**

> ⚠️ 两种方式 admin 密码不同（seed.sql=`admin`，DataInitConfig=`admin123`），混用易混淆，建议统一用其中一种。

### 默认账号
| 角色 | 账号 | 密码 | 来源 |
|------|------|------|------|
| 管理员 | admin | admin123 | DataInitConfig 代码初始化 |
| 管理员 | admin | admin | seed.sql 脚本初始化 |

## 五、启动项目

### 1. 启动后端（端口 3001）
```powershell
# 配置环境变量（见第三节）— 仅需 JAVA_HOME
$env:JAVA_HOME = "C:\Program Files\Java\jdk-17.0.17.10-hotspot"
$env:PATH      = "$env:JAVA_HOME\bin;$env:PATH"

# 编译并启动（在后端目录执行，用 Maven Wrapper）
cd hotel-booking-system\backend
.\mvnw.cmd spring-boot:run
```
- 启动成功标志：控制台输出 `Started HotelBookingApplication` + `Tomcat started on port 3001`
- API Base URL：`http://localhost:3001/api`

### 2. 启动前端（端口 5173）
```powershell
cd hotel-booking-system\frontend
npm run dev
```
- 启动成功标志：Vite 输出 `Local: http://localhost:5173/`
- 前端通过 [api/index.ts](frontend/src/api/index.ts) 中 `baseURL: 'http://localhost:3001/api'` 直连后端（**无需 Vite 代理**）

## 八、常见问题排查

| 问题 | 原因 | 解决 |
|------|------|------|
| `mvn : 无法识别` | 未设置 MAVEN_HOME/PATH | ✅ 改用 `.\mvnw.cmd`（Maven Wrapper），仅需 JAVA_HOME |
| `JAVA_HOME is not defined correctly` | 未设置 JAVA_HOME | 执行第三节环境变量配置 |
| 后端启动报数据库连接失败 | MySQL 未启动或密码不符 | 确认 MySQL 服务运行，密码为 `123456`（见 application.yml） |
| 用户登录提示"密码错误" | 原查询只匹配 phone/email，用姓名登录查不到 | ✅ 已修复：UserMapper 查询增加 username 匹配 |
| 前端 401 跳转登录 | token 过期或未登录 | 拦截器自动清除 localStorage 并跳转 `/login` |
| 管理员登录报错 | `setAdminToken` 方法不存在 | ✅ 已修复：auth store 添加 setAdminData 方法 |
