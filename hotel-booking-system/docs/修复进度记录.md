## 四、遇到的问题与决策

1. **数据库列名命名不一致**：schema.sql 使用 snake_case（image_url, created_at），但实际数据库表使用 camelCase（imageUrl, createdAt）。实体类 @TableField 注解值需用 camelCase，否则报 "Unknown column" 错误。
2. **管理员密码不统一**：seed.sql 使用 admin/admin（明文），DataInitConfig 使用 admin/admin123（BCrypt 加密）。当前以 DataInitConfig 为准，清空 admins 表重启即可重置。
3. **前后端 Restaurant 字段不一致**：前端类型用 `title`，后端实体用 `name`，运行时餐厅名称可能不显示（待 P4-5 修复）。
4. **tsconfig 严格度调整**：为加速构建通过，将 noUnusedLocals/noUnusedParameters 设为 false，后续可重新启用并清理。
5. **数据库 schema 与实际不符**：schema.sql 中 users 表列名为 `name`，但实际数据库列名为 `username`。User 实体 `@TableField("username") private String name` 在 MyBatis-Plus 自动 CRUD 中生效，但自定义 @Select 查询不使用 @TableField，需用 `username AS name` 别名映射。
6. **用户登录"密码错误"bug**：根因是 findByPhoneOrEmail 只查 phone/email，用户用姓名登录时查不到。修复为支持 username/phone/email 三种登录方式。
